# Ranjith Estates

A responsive React and Vite real-estate experience featuring home discovery, property search and filters, property and agent details, saved homes, sign-in/sign-up, and a contact form.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```

## Features

- Browse homes and filter by location, listing type, property type, and bedrooms.
- View property galleries, features, pricing, agent information, and send a viewing inquiry.
- Save homes across browser sessions. Saved homes are available after creating a demo account or signing in.
- Demo authentication is stored in the current browser only; any valid email and password with at least six characters can be used. There is no backend or real account service.
- Contact and viewing inquiry forms provide an in-app confirmation. Connect a backend/email service to deliver submissions.
- Responsive layouts for mobile, tablet, and desktop.
